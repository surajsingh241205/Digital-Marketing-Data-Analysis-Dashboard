# 📊 Digital Marketing Analytics Dashboard | Power BI

An end-to-end **Business Intelligence (BI)** project built using **Power BI**, **Microsoft Excel**, and **digital marketing analytics** to analyze the online performance of **Linus Business Solutions**.

> **Note:** This repository does **not** include the original dataset because it contains confidential business data from the company's website and Instagram account. The repository includes the Power BI dashboard screenshots, and project documentation for demonstration purposes only.

---

# Project Overview

This project transforms raw digital marketing data into actionable business insights through an interactive Power BI dashboard.

The dashboard consolidates website analytics, Google Search Console SEO metrics, and Instagram performance into a single reporting solution, enabling stakeholders to monitor KPIs, evaluate marketing performance, and make data-driven decisions.

The complete analytics pipeline includes:

- Data Collection
- Data Cleaning
- Data Transformation
- Data Modeling
- KPI Development
- Dashboard Design
- Business Insights
- Strategic Recommendations

---

# Business Problem

Businesses often receive marketing data from multiple platforms such as:

- Google Analytics
- Google Search Console
- Instagram Insights

Analyzing these datasets separately makes it difficult to understand overall marketing performance.

This project combines these data sources into a unified Power BI dashboard that provides clear KPIs and actionable insights.

## 1️⃣ Overview Dashboard

![Dashboard 1](https://github.com/surajsingh241205/Digital-Marketing-Data-Analysis-Dashboard/blob/main/Dashboard%20Images/1.PNG?raw=true)

### Purpose

Provides a high-level summary of the company's digital marketing performance for the selected reporting period.

### KPIs

- Visitors
- Sessions
- Search Clicks
- Search Impressions
- Instagram Reach
- Instagram Views

### Visualizations

- Website Traffic Channels
- Top Website Pages
- Top Search Queries
- Executive Business Insights

### Key Insights

- Organic Search was the primary website traffic source.
- Homepage generated the highest number of visits.
- Brand keywords produced the highest organic search clicks.
- Instagram contributed significantly to overall brand visibility.
- Dashboard includes executive recommendations for improving traffic and lead generation.
